#  Topcoat Web Workspace
Generated by TeaQL. This application reuses the generated
`perfect-service-core` domain crate.
## Quick Start
```bash
# 1. Read AGENTS.md for API usage instructions
# 2. Configure database URL when the generated domain uses a SQL provider
export _DATABASE_URL="sqlite://data.db"
# 3. Optionally configure bind address
export _BIND_ADDR="127.0.0.1:3000"
# 4. Run
cargo run
```
## Endpoints
- `GET /`
- `GET /health`
## Request Context
Every request receives an independent TeaQL `UserContext`. HTTP metadata,
including client IP headers, User-Agent, URI, method, and request headers, is
stored as a typed resource inside that `UserContext`.
TeaQL resources are never registered in Topcoat's application context.
